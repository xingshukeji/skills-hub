# Windows 微信操作知识

该专题来自 Windows 桌面操作经验，只在当前窗口观察能确认相同控件时适用。不同版本、布局或平台必须重新定位，不能套固定屏幕坐标。

先核对当前账号、会话标题与消息区域。搜索结果、侧栏会话和聊天正文是不同区域；搜索后进入目标并回读标题。仅看到搜索词不能证明已经进入同名会话。

引用消息时先找到确定的可见消息，再右键打开菜单。优先从当前控件树找唯一“引用”菜单项；无控件信息时用当前菜单截图/OCR 定位。点击后回读引用预览中的正文或作者，确认归属。菜单可能随消息类型变化，不能固定点击第几项。

正文由调用方明确提供。输入后核对内容，发送操作及所需审批依据当前用户或业务 Skill 的授权。通用工具没有“首次接管必须发言”、身份前缀、发言频率或连续参与规则。看到输入框内容不能证明已发送；以新消息出现及会话上下文为证。

语音优先使用应用原生转文字入口；先确认具体语音消息和当前菜单，再读取转写结果。没有原生结果时，只能使用调用方显式提供且获授权的 ASR 工具；不可凭气泡位置、时长或上下文补造内容。本工具没有内置云端 ASR 或自动回复。

采集历史按当前任务限定范围，短距离滚动并核对重叠候选。OCR 的左右和 role_hint 只作候选，不能当作真实发送者或完整聊天历史。业务需要保存状态时由其调用方维护，安装及通用采集不创建个人风格或草稿审批数据。
