# Bounded execution examples

- A cross-layer feature with an old UI evaluator still active is split only after the actual path is traced; the evaluator gap belongs to one unit and has an observable acceptance assertion. Parallel consumers do not each patch the common compiler.
- A one-file label fix proceeds directly with proportionate verification; this method does not require a new task, plan, dependency graph or consumer rebuild.
- A failed consumer contract check returns to its owner with a reproducible case; it does not authorize an execution task to create another task or repair unrelated services.
- A verified candidate remains usable when only documentation changes. A changed query contract requires only the affected evidence to be renewed; old results are not silently relabelled as current.
- An actual live build or a newly discovered defect is meaningful progress or waiting. Repeating passed checks without new evidence triggers reassessment, not more tests or premature completion.
- A durable import job already stores its immutable plan and committed checkpoints. Review first asks whether a second client ledger or confirmation token protects any uncovered fact; it can remove them while retaining current authorization and revision matching. It does not respond by designing another token-recovery protocol.
- A completed import is followed by an authorized business edit or loss of result-read permission. The original commit remains completed; current access still governs what can be read. A later diagnostic cannot turn that successful import into a failed write or trigger replay.
- A user asks to simplify an approved plan. Required outcomes remain, but author-invented constraints can be reconsidered. A user explicitly requiring a signed third-party artifact is the counterexample: signature and identity checks still protect a real boundary.
- A user requests only a review. Findings may recommend removal, but the reviewer leaves product files unchanged. Existing implementation authority covers the necessary follow-up fixes without another approval round.
