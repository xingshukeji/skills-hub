# 铵帮文件报价核验

案例由 Excel 文件维护，不进入低代码平台。页面和 CLI 使用铵帮同一文件解析及核验服务，计算复用销售当前资料、当前业务日期和应用当前选用的报价函数。

使用同一目标租户的管理员已保存会话，并明确铵帮宿主与应用：

```text
xrain-cli anbang quotation defaults --workforce <铵帮宿主地址> --application-id <应用ID> --profile <租户连接> --auth session --out cases.xlsx --json
xrain-cli anbang quotation verify --workforce <铵帮宿主地址> --application-id <应用ID> --profile <租户连接> --auth session --cases cases.xlsx --out report.xlsx --json
```

省略 `--cases` 时读取目标宿主随制品交付的默认案例。`--case CC-001,QD-001` 选择文件内明确编号；停用行不运行。输出文件必须使用新路径，不覆盖已有文件。

核验先校验当前用户与租户，宿主继续检查应用准入、管理资格和字段权限。CLI 不切换为后台身份，不发布函数、不改变选版，也不创建顾客或正式报价。普通销售不能通过此命令取得管理员明细。

每行输出状态、预期与实际、差异及计算依据。标准金额按销售保存精度比较，零值和空标准分开。无标准、字段不可读及结果缺失不能计为通过。预期不能报价时还须核对具体业务原因；权限或服务失败不能作为正常业务阻碍通过。

全部所选启用行通过时退出码为零。有差异、失败、无标准或无法核验时返回非零，同时保留已完成结果。单行业务错误不影响其他行；认证或授权失效停止后续请求。不自动重试计算，不重放整批。取消保留已完成行，不证明已经发出的请求未执行。

核验报告是当前运行结果，导出不会更新标准答案。资料、日期或函数变化后应重新核验，不能仅据金额不同断定算法有误。开发者 `project function test` 仍测试指定版本和固定输入，不能代替当前销售完整链路核验。
