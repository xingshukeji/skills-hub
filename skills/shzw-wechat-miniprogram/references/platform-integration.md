# XRain 与 Workforce 接入和验证

## 找到项目事实

- 从铵帮项目入口找到原生小程序 Runbook。启动统一宿主、生成本机覆盖以及查询当前 AppID、登录方式和合成夹具都按该 Runbook 执行。小程序调用现有平台密码登录、租户选择、顾客 API 和接待 Runtime。接口返回的字段身份、权限、脱敏、接待资格和确认状态由服务负责。界面按实际用户能执行的动作呈现。
- 默认开发路径复用 Workforce 的现有启动入口和目标测试租户。用项目生成的本机环境和私有配置在模拟器迭代。先确认实际加载的本地文件和服务，再定位失败。可在已授权范围内调整本机覆盖、测试数据格式和自动化定位。提交前逐文件审查。夹具按现有手机号格式、业务校验和权限修正。
- 微信工具登录用于打开和调试项目，平台业务账号用于访问租户记录和助手。用责任项目确认的固定测试身份和该账号可访问的合成数据。对指定账号的验收沿用该账号，遇到不可用先沿授权、租户及应用入口定位。运行持久联调脚本前核对创建、修改、发送与退出等实际副作用。受管秘密通过原有安全入口读入，留在本机执行过程。

## 从原页面读回业务结果

按改动选择下列链路。整条接待流程联调时，按顺序走通并保留同一身份、顾客与接待会话的关联。

| 原生页面动作 | 核对结果 |
|---|---|
| 打开小程序并登录 | 从原登录页提交。验证实际租户和可访问范围，打开顾客列表。按实际交互处理选择企业、会话失效或账号切换。 |
| 搜索并打开顾客 | 基于实际页面输入命中目标。用记录 ID 与显示名确认，核对角色可见字段和脱敏值。 |
| 登记或编辑资料 | 只在获准租户对合成顾客操作。输入后核对字段值，保存一次，再通过搜索、重开或同身份 API 读回同一记录。需要复用的具名夹具，编辑验证结束后按项目约定保留其标识，恢复前核对仍是本次写入。 |
| 发起接待并发送消息 | 从目标顾客选择已授权接待助手，读取被关联的会话 ID。提交一次测试消息，按该会话的真实持久回执、历史和最终助手回复核对。遇到业务确认等待实际决定。 |
| 后台恢复和退出 | 通过实际可用的模拟器或设备生命周期入口验证返回后原会话、草稿及未完成操作的状态。退出后回到登录页，核对上一身份的顾客或草稿未泄漏。组件生命周期测试提供局部证据，实际切后台能力单独确认。 |

保存、创建会话或发送超时时，优先用原记录 ID、操作标识和已有关联回读。确认接收与最终回复分别取证。若返回只证明某次动作已派发，继续等目的页或业务结果。无法确认副作用时保留原步骤及结果，避免重放写入。

## 模拟器与设备

模拟器可使用项目约定的回环宿主及本机私有覆盖。真实设备上的回环地址属于该设备。真机联调前按项目与微信平台确认设备可达的获准入口、合法请求域名、对应身份和真机调试权限。通过官方预览或真机调试入口按本次目标操作。仅在目标需要并取得对应授权时改后台域名、上传或发布。相机、麦克风、扫码、前后台切换和域名实际请求按设备与场景取证。
