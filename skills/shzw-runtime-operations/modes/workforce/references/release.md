# 本机源码与运行结果不一致

沿当前开发入口核对源码、构建输出、实际安装包、运行进程及浏览器业务结果。从项目 Runbook 和启动输出取得本机加载路径、版本、摘要及配置来源，不猜版本接口，也不以源码已修改推断进程已加载。

| 证据差异 | 处理 |
| --- | --- |
| 只检查、构建成功 | 核对本机启动入口实际消费的包和构建输出 |
| 本机实例仍加载旧包 | 按当前开发 Runbook 准备源码与依赖，正常重启本次自有进程并回读加载结果 |
| 本机实例新、页面旧 | 核对浏览器实际入口、本机静态资源来源及缓存 |
| 源码相同、行为不同 | 查实际加载配置、应用安装、装配及原用户准入 |

重启保留 Runtime、定义、会话、工作区和业务数据。相邻源码变化按当前开发入口构建并核对消费者实际加载的原包；不从输出目录挑选版本，也不靠重新初始化业务环境解决来源不一致。

共享依赖返回不支持、连接失败或权限错误时，记录目标与实际响应，按接入合同定位；需要外部服务处理的部分交其所有者。本机结果只证明本次开发实例。最后使用原用户从本机入口复测原动作及持久结果。
