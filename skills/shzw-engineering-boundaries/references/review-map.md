# 审查维度

首次系统性调查用于发现遗漏；局部修改只选相关行。每个结论区分已核实问题、合理机制、正在修改及证据不足。不因某行尚未发现问题而创建组件或测试项目。

| 维度 | 沿真实调用链检查 | 典型处置与必须保留的约束 |
|---|---|---|
| 需求与公共抽象 | 谁使用公共层；抽象是否只包装一个技术选择；同名概念是否实际不同 | 没有独立消费者的扩展点不预建；已有公共契约由真实消费者决定兼容 |
| 依赖与版本 | 包声明、锁、安装源、本地源码消费与实际运行包是否对应 | 包管理器持有解析、下载和缓存；不复制安装数据库；本地覆盖须有明确恢复入口 |
| 文件消费 | 文件职责、生产者、消费者、执行时机、解析接口及写入所有者是否对应 | 按[文件消费职责边界](file-consumption.md)检查隐含接口；保留编译、静态分析、文档协议及业务文件读取，不按目录或扩展名一概禁止 |
| 构建与制品 | 编译是否被发布策略阻断；构建是否读取运行凭据；制品能否离开源码运行 | 构建可重复；发布维护不可变版本；跨信任边界的制品完整性继续由接收者验证 |
| 配置、身份与秘密 | 配置优先级是否清楚；环境标签是否隐式改规则或账号；无效值是否触发自动改写 | 配置在组合入口解析；身份初始化使用明确维护入口；保留租户和授权约束 |
| 启动、连接与健康 | 配置缺失、进程存活、服务就绪和业务可用是否混淆；诊断是否改了状态 | liveness 关注自身；readiness 只覆盖实际接流量所需条件；可选依赖不拖垮无关功能 |
| 生命周期与资源 | 谁持有缓存、锁、队列、订阅和连接；保留条数/字节及过期后辅助键是否增长；正常退出、取消、异常和热更新何时释放 | 资源所有者关闭所属连接与任务；验证旧连接、在途工作及释放后基线；状态恢复归数据或 Runtime 所有者，不清空状态掩盖故障 |
| 数据、迁移与初始化 | 数据唯一事实源在哪里；启动是否同时迁移、造演示数据、覆盖在线配置 | 缓存、种子和正式数据分开；维护操作显式且可重复；回退程序不等于能回退数据 |
| 故障、超时与重试 | 根因在哪层丢失；嵌套重试是否放大负载；写入结果未知时是否重放 | 在有上下文的层决策，传递取消与总预算；必要幂等和并发冲突不能随 hash 清理删除 |
| 权限与信任边界 | 谁最终授权；应用是否代管平台或部署策略；重复校验是否防止不同损害 | 保留业务权限、租户隔离、内容和数据完整性；网络入口政策归明确平台所有者 |
| 测试与证据 | 测试调用公开入口还是复制实现；替身与真实服务差异；打包结果是否被消费 | 断言业务不变量和可达故障；类型与单测不能替代真实依赖证据，也不强迫每次全量回归 |
| 诊断与使用负担 | 新开发者和运维人员需要知道多少隐含步骤；用户是否看到内部协议状态 | 真实操作指南归正式入口；有用日志和指标归运营需求；用户界面不承载工程过程 |
| CI/CD、治理与退出 | CI 是否复制产品命令、版本和校验；文档是否参与运行资格；旧入口有无真实消费者 | 产品拥有构建契约；CI 调用契约；文档检查服务编辑质量；按消费关系退役旧路径 |

## 判定状态是否自我服务

先问：如果删除这项机制，哪个外部用户、工具或持久数据不变量会受影响？答案若只有“另一个自建检查会失败”，继续追到最终消费者。闭环内互相验证不等于存在外部需求。

- **通常可删除的闭环**：源码指纹 → 启动资格文件 → 浏览器轮询 → 状态同步 → 为同步失败增加恢复脚本。若没有独立产品能力消费这些状态，应整体退役。
- **不能据此删除的状态**：两个进程可能同时写同一文件时的写者锁；响应丢失后的业务幂等记录；来源数据变化后的并发版本。它们保护机制之外的业务或数据事实。
- **需要重新安置的检查**：包损坏校验应在接收或安装边界；发布版本不可覆盖应在发布边界；配置不可解析应在组合入口。它们不自动要求每次业务请求或普通编译重复执行。

## 环境比较的最小表

只填受影响项。表中“应一致”指语义和同次交付关系，不代表每台机器路径、数据及字节完全相同。

| 观察对象 | 应一致 | 允许差异 |
|---|---|---|
| 业务行为 | 授权、输入含义、状态变更和失败约定 | 调试信息与外部观测方式 |
| 依赖消费 | 公开导出、兼容声明、版本解析规则 | 正在开发的本地包与正式固定包；必须知道当前消费哪一种 |
| 构建运行 | 构建入口及产物契约；同一目标平台从测试晋级到生产的制品 | 开发监听、压缩、source map、多平台产物；涉及运行行为的差异须验证 |
| 配置身份 | 参数含义、优先级、租户与权限逻辑 | 地址、凭据、账号数量、资源上限和外部连接方式 |
| 存储服务 | 持久格式、并发、协议、迁移及恢复语义 | 隔离测试数据、独立实例、容量；不同引擎需额外兼容证据 |
| 生命周期 | 资源所有权、关闭及异常恢复约定 | 前台终端、容器或服务管理器；Windows/Linux 行为分别核对 |

## 按责任减少检查

不能把所有检查移动到 CI。用户输入、访问授权、并发写入及远端运行故障发生在运行时，必须在具有真实上下文的边界处理。也不能把 CI 检查搬到正常启动，以启动失败代替交付保证。

缓存不应成为不可恢复的事实源。仅为加速而新增的缓存，应说明相对于现成工具的收益，以及失效或丢失后的正确行为。删除缓存不等于绕过制品真实性、权限或数据一致性检查。
