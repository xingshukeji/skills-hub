# 业务授权设计

## 从职责得到授权方案

将参与者映射到动作、字段和记录范围。例如维修业务可设计以下职责，并非预置角色：

| 参与者 | 业务动作 | 数据范围与字段 |
| --- | --- | --- |
| 报修人 | 创建申请、查看进展、补充描述 | 本人申请；可读处理结果，不编辑处理结论 |
| 维修人员 | 领取、记录处理过程、完成维修 | 分派给自己的申请；可写处理记录及实际完成数据 |
| 调度人员 | 分派、改派、查看本部门进度 | 本部门业务范围；不因“调度”角色名自动取得全租户权限 |

“本人/本部门”须对应真实主体与字段。Owner、负责人 UserRef、创建人可能不同，字段名本身不授予权限。

## 几个独立的判断

| 判断 | 实际含义 |
| --- | --- |
| 登录与租户成员 | 用户身份有效，并且属于目标租户；角色名称不建立成员资格 |
| 应用准入 | 该用户能进入这个应用；不自动取得其全部业务数据 |
| 操作能力 | 有权执行对象动作、接口或自定义业务动作 |
| 字段访问 | 当前字段允许读取、创建或编辑；读取还可能脱敏 |
| 记录范围 | Owner、共享规则、人工分享或其他实际支持的范围允许访问这一条记录 |
| 自动化执行 | 实际运行工具、函数或流程的主体拥有对应能力；定义、工具装配和执行资格也要成立 |

页面显示能力，服务端执行授权；业务处理器另检查状态与规则。

## 角色、权限集和权限

全员来源见[初始化基础](initialized-platform.md)。专项职责用“用户 → 角色 → 权限集 → 权限”，也可直接绑定普通权限集；同一身份承担多个角色。权限可有多个来源，撤销一条绑定未必消除有效权限。

对象/字段权限从派生目录取实际名称；专有动作声明 custom.* 并由处理器检查，见[元数据与前端](metadata-and-ui.md)。

## 记录范围怎么落地

范围使用 Owner、人工分享或共享规则。页面筛选只能缩小结果，不能代替后端授权；部门层级、直接上级也不自动授予下属记录。

“本部门且有角色”须将两个主体条件放入 all，并配置记录部门条件；角色直授与主体条件是 OR，不能同时直授该角色。请求见[组织与协作](organization-and-collaboration.md)。验证范围内外记录，并检查其他来源是否扩大权限。

## 跨系统与自动化的执行身份

会话确定发起者，实际凭据确定数据访问主体。跨系统按来源与租户映射身份，业务参数中的 userId 不替代认证。

| 场景 | 权限如何落地 |
| --- | --- |
| 用当前用户访问 XRain | 可信执行绑定或当前会话客户端，平台执行对象、字段和记录授权 |
| 用当前用户访问 ERP | 原系统认可的用户凭据或委托机制；原系统检查其用户范围 |
| 用共享连接器凭据访问远端 | 平台接口权限控制谁能发起；远端按连接器主体授权，个人业务范围由受管操作另行落实 |
| 通过编排发布一个组合操作 | 外层入口按完整业务能力授权；原生记录仍检查执行者的数据权限，内部 raw HTTP 调用按编排规则执行 |
| 记录 After Trigger | 保留事件操作者及上下文；Worker 不自动变为管理员 |
| 普通定时 Routine | 使用配置的实际执行成员；维护 Owner 不等于运行主体 |
| 企业受管后台操作 | 使用已经定义的用途与身份，明确可执行业务及对调用者的检查 |

原系统授权、[Token 主体](configuration-and-api.md)、[智能体资格](agent-access.md)分别成立。拒绝时定位具体系统与主体，保留原因，不改用管理员绕过。

## 实现与检查入口

SDK 用 applicationAdmission 读准入、context 读主体和权限。已有 CLI 可按当前认证目标操作其支持的租户安全资源：

| 需求 | 命令形式 |
| --- | --- |
| 查看用户授权 | `security user show <用户名>` |
| 查看角色 | `security role show <角色名>` |
| 查看权限集 | `security permission-set show <权限集名>` |
| 将已有角色分配给已有用户 | `security user grant-role <用户名> --roles <角色名>` |
| 将已有权限集关联角色 | `security role grant-permission-set <角色名> --permission-sets <权限集名>` |

管理写入区分增量与集合替换；替换须合并保留其他绑定，修订冲突后重读。页面按当前主体的 object.access 处理字段能力；以相应业务角色验证允许与拒绝结果，管理员成功或按钮隐藏不能代替验证。
