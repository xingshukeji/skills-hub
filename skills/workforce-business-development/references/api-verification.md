# API 实测范围与已知差异

本文记录验证依据与边界，无需每次重复。调用合同见[业务 API](business-api.md)，真实返回见[脱敏样例](../assets/http-contract-samples.json)。

## 本次验证条件

- 日期：2026-10-23；目标为铵帮使用的中央测试租户。
- 使用已登记维护者与普通成员的租户登录态，实际调用服务。
- 共保存 117 次请求：GET 75、POST 38、PUT 2、DELETE 2。返回 200/201/204 共 96 次；其余包含有意验证的权限、冲突、无结果和错误分支，不将它们计为全部成功。
- 早期 SDK 示例依据 `@xrain/workforce-application` 0.3.5、`@xrain/xrain-agent-runtime` 0.2.0 的交付类型；本次用 Workforce 0.3.8 公共导出的 XRainRuntimeClient 验证 context/queryBatch。目标能力仍以安装版本为准。
- 写入限于新建的合成对象、5 个字段、1 个视图和 3 条记录；清理后记录数为 0，按删除影响与修订合同移除模型，describe 返回 404。
- 未改账号或既有授权，未安装升级应用、发送通知或访问真实邮箱内容。

完整记录留在忽略的本地验证目录，Skill 无此依赖。随附 18 组样例替换环境身份和 traceId，保留状态码、正文类型与响应摘要；摘录用 responseExcerpt 和 omittedResponsePaths 标明。

## 已取得真实返回的能力

| 能力 | 实际核对结果 | 不能由此推断 |
| --- | --- | --- |
| 当前身份与基础权限 | 两个主体的 context；全员权限集含 23 项，roles/users 为空但普通成员具有基础入口权限 | 不能推断普通成员具备业务对象、字段或通知权限 |
| 业务发现与描述 | 维护者可见业务对象；普通成员 objects 为空，describe 缺入口权限时返回 403；User 的 code 为 runtime.User | 管理员描述不代表普通成员看到相同字段 |
| 创建模型与字段 | 对象及五种字段创建均为 201，回读有效字段及访问描述 | 未测试失败部署恢复或存量破坏性字段迁移 |
| 记录增改查删 | 单条创建/读取/更新/删除、批量创建/更新/删除均核对返回和结果 | 未测试受保护 User 的写入，不把普通 CRUD 当账号管理 |
| 查询与统计 | 分页、总数、sum 聚合、count、distinct、first、single、多查询及导出 | 导出测试只证明 JSON 分页，未生成 Excel 或证明快照一致性 |
| 并发与批量回滚 | 旧值不符返回 409；批量中第二项冲突后，第一项仍保持原值 | 未验证跨 HTTP 批次或外部系统事务 |
| 选项与视图 | 多选字段分页、Task 单选字段分页；视图转换、显示覆盖、条件填色和旧修订冲突 | 不能将 options 用于 UserRef/Lookup；记录类型范围写入未实测 |
| 历史与记录协作 | 历史分页、分享 capability/recipients/eligibility/list；无对象 Read 的接收人不合格，Owner 转移被拒绝 | 没有给其他人新增分享，也未验证成功的跨人 Owner 转移 |
| 人员与组织 | 成员分页/单人资料、目录可见模式；组织树返回空数组 | 未创建部门或调整成员组织关系 |
| 初始化选项 | 五个默认选项集及各项返回核对，customerStage.closed 确为停用 | 这些是当前租户状态，不保证其他旧租户存在全部记录 |
| 设置与时间 | 未配置用户设置返回 404 空正文；地区默认为空对象；当地时刻解析及夏令时业务日边界成功 | 未写入个人偏好或租户默认设置 |
| 平台变量 | 返回元信息数组及 hasValue | 未写入或读取变量明文 |
| 编排 | 取得 47 项 callable；实际执行查询编排，isSuccess 为 true | 不代表每个 callable 都已执行或均有完整 signature |
| 定时能力 | 分页列表、执行人配置读取、Daily 调度预览 | 执行人为 null，未启用或运行定时任务 |
| HTTP 集成 | 连接器及接口目录真实返回，含调用路径、权限名和输入变量 | 未调用现有消息投递接口或远端 ERP |
| 应用与助手 | 应用准入、函数选择、智能体绑定和个人资格；消息授权/应用上下文拒绝 | 未更改绑定、订阅或函数版本，也未运行现有业务算法 |
| 个人邮箱 | 提供商返回 4 项；当前测试成员 accounts 为空 | 未验证收件、正文、草稿或发送 |
| 包生命周期 | 已安装包、安装状态、136 个组件、操作分页及最近操作详情 | 未升级、卸载、重试或恢复现有包 |
| 回收站 | resources 返回空数组 | 未验证有内容的条目形状或恢复动作 |

数值与时间结果：金额字符串保持精度；DateTime 七位小数截为六位微秒 UTC；三条记录总额 `"60.90"` 不随分页缩小；纽约 2026-11-01 为 25 小时，01:30 返回两个时刻候选。接口差异已写入[业务 API](business-api.md)及相应专题。

## 服务错误与未执行部分

`tenant-api-catalog?catalog=external` 和 `catalog=internal` 分别返回 31、35 项；`catalog=directory` 和 `catalog=external&format=openapi` 均返回 HTTP 500，正文 `{message, details, traceId}`。这是未修复的测试服务错误，应保留其状态与正文。

文件服务、API Token 签发/显示/撤销、设置 PUT、变量写入、外部投递、邮箱检索与草稿、Trigger、定时启用/运行、现有应用函数执行和安装升级恢复等，仅核对接口或发布包合同，**未完成端到端实测**；使用时再验证对应业务链路。
