# 产品知识与责任项目

本目录随技能完整交付，供业务开发、审查、排障和测试按需读取。读取专题不启动另一整套任务。使用公开能力无需平台私有源码；修改平台自身时，通过当前项目入口进入实际责任仓库。

| 知识 | 产品事实所有者 | 当前维护者工作空间定位 |
|---|---|---|
| 对象、字段、授权、业务编排、连接器、记录 API、应用包协议 | XRain | all_in_one 中的 XRain 项目 |
| 公共数据访问、事务、provider、基础授权与 AiInfra.Abp.* API | AiInfra | all_in_one 中的 LLM_backend_packages 项目 |
| 人与 AI 协作、消息、Task、应用宿主及 Workforce SDK | Workforce | xrain-workforce |
| Agent Runtime、Session、执行和扩展协议 | XRain Agent Runtime | xrain-harness |
| 统一认证身份与 OIDC | XRain Auth | xrain-oauth |
| 市场目录、包提交与分发 | 应用市场 | xrain-app-exchange |
| 企业业务差异、角色用途和工作结果 | 具体业务项目 | 由目标项目入口定位，例如 anbang |

当前工作空间定位仅用于维护者路由，不要求使用者拥有同名目录。通过目标 AGENTS 或已保存项目找到真实 Local 路径，不能从技能安装位置拼接相邻源码。

各专题中的 API、SDK 导出、限制和实例分别保留其适用条件；历史实测范围不扩大为当前所有目标承诺。能力或协议变化时，由产品责任项目更新事实，在 skills-hub 更新受影响的公开使用知识、示例和案例，再更新完整消费目录。内部路径只提供维护定位，不能取代公开用法。

存在缺口时，区分公开能力未支持、目标版本未提供、配置授权不足及本次未验证。禁止从源码存在、管理员结果、示例成功或单个制品推断其他用户和环境可用。
