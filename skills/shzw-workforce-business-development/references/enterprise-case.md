# 企业销售案例

产品事实：XRain / Workforce 与具体业务项目；业务差异由目标项目维护。
维护与适用：本专题由 skills-hub 维护，面向公开能力的业务使用；接口、示例与历史实测的原有适用条件继续有效。内部修改由目标项目入口定位源码与测试。

本例提炼自企业销售项目及其发布包，业务名称与权限命名已通用化。它说明一种实现选择，不要求访问原仓库，也不代表所有在线配置已启用。

## 平台与业务的分工

应用支持车型查询、政策解释、购车测算、方案确认和特价申请：

| 实现位置 | 职责 |
| --- | --- |
| 业务模型与资源生成器 | 声明对象、字段、选项、关联和 `custom.sales.*` 权限，保留稳定身份 |
| 数据适配层 | 使用平台 CRUD、查询和 expectedValues 条件更新 |
| 企业服务与算法 | 判断政策、成本、预算含义，生成带单位的业务结果 |
| 宿主、页面和工具 | 共享业务处理器，复用登录、导航、会话与公共组件 |
| 函数产物及应用选择 | 维护算法源码、合同和不可变版本，与模型包分别交付 |

本例的 Host/Client 插件通过包入口、`dsh.bundle.patch` 和 profile 装配；`apply(ctx, config)` 用 `ctx.workforceApplications.register` 注册入口、`ctx.workforceHttp.register` 注册处理器，借 `ctx.effect` 释放。其他宿主按其公开扩展合同接入。

初始化复用 `xrain-all-employees`、User 和已安装的 Task/频道资源，只补专项权限。`workforceWorkGuide__c` 是按需 User 扩展，不是所有新租户的内置字段，见[初始化基础](initialized-platform.md)。

## 独立业务事实与职责

测算记录关联车型、需求修订、采用依据与函数版本；确认记录关联被确认方案，成交另有业务事实。政策变化后可以生成新测算并保留旧结果。

本例另存计算依据快照用于历史重现，字段与快照需保持一致。普通表单可直接用平台字段和变更历史，无需照搬 `content__c` 或双份内容。

| 职责 | 示例能力 |
| --- | --- |
| 销售 | 测算、接待、本人申请及成交记录 |
| 资料维护人员 | `custom.sales.catalog.manage`、`custom.sales.policy.manage`、`custom.sales.quote.review` |
| 主管 | `custom.sales.price.approve`、`custom.sales.quote.review`、`custom.sales.report.read` |

职责之外仍需应用准入、对象/字段权限与记录范围。本例用销售身份读取可见资料，受管后台操作复用配置身份并检查业务调用者；执行主体按目标项目选择。

## 端到端测算

1. 智能体识别预算与车型条件，将业务参数交给服务工具。
2. 宿主提供可信主体、租户及本场景的应用/顾客绑定。
3. 服务读取该用户可见的车型和政策，调用应用选定算法。
4. 平台保存结果与必要依据，页面和工具使用同一结果。
5. 确认方案、向客户提供方案或成交由相应动作记录，不因计算完成自动发生。

本例以“分”的整数字符串处理金额、以分子/分母处理比例；其他业务明确自己的单位和精度即可。智能体定义导出与在线更新、工具声明与宿主处理器装配分别完成。

新增“按额定功率筛选车型”时，只补字段/单位、查询条件、页面或工具参数及字段授权；品牌测算规则变化则修改算法、依据和函数选择。通用接入见[业务实现](implementation.md)，原系统已有能力见[系统集成](integration.md)。
