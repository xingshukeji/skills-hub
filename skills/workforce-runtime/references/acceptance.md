# 使用验收

按本次目标及实例实际装配选场景，不每次跑全集。用原固定身份完成“入口 → 操作 → 回读 → 刷新/重连”，只报告通过、失败、未执行或阻断。

| 目标 | 必要结果与边界 |
| --- | --- |
| 登录/新用户 | 原用户、租户、应用入口及职责内动作；密码验证需真正退出后重新输入 |
| 数据页面 | 查询、筛选、已授权保存后刷新；用范围内/外记录及只读字段区分权限，空列表不能证明过滤正确 |
| 安装/升级 | 目标安装版本、组件和普通用户操作；保留 NotChecked 与未验证项 |
| 智能体切换 | 两个明显不同定义在各自会话生效；旧会话历史与不同用户/租户隔离 |
| AI 跟进/恢复 | 本轮执行、持久消息、任务状态、实际交付一致；按原问题复测断线、接管或改派无重复/迟到写入 |
| 空态/错误态 | 无数据、无智能体或无权限有可理解结果；恢复条件后不残留旧身份数据 |

记录场景、实际入口/版本、身份用途、预期、结果及最小脱敏证据。健康接口、单测、管理员或模型自述不能替代普通用户结果。发送、删除等写入使用本次授权；仅验收时不扩展为产品修复。缺浏览器或缺数据就保留覆盖缺口。
