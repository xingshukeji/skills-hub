## 建议先做

### 写入结果未知时的恢复信息

分类：现有恢复体验缺陷。CLI 维护者在 skills-hub 处理。

普通记录更新、删除、未使用 requestKey 的创建，以及部分安全管理写入，发生连接中断时可能只返回通用网络错误。服务端已经完成写入的情况下，使用者缺少原对象、记录和回读指引。当前 CLI 不自动重试；该问题不证明平台会重复写入。

补齐操作、目标 profile、对象和记录等可安全展示的上下文。区分服务端拒绝与提交结果未知。按原 ID 或已有回执查询，不自动重放写入，不为严格 DTO 增加服务端未声明的幂等字段。回读只能说明当前值时，不将其表述为本次写入成功。

验收：在隔离服务中覆盖写入前断开、提交后回执丢失、401/403/409 和正常成功；核对请求次数、持久结果、错误上下文和恢复指引。批量命令保留此前已完成的结果。已有带键创建、定义保存、Host 设置和安装操作的恢复行为继续成立。

依据：[记录命令](commands.mjs)、[HTTP 调用](http.mjs)、[带键创建](record-creation.mjs)、[现有设计](DESIGN.md)。

### Runtime 显式操作控制

分类：能力未接入。CLI 由 skills-hub 实施；xrain-harness 核对 Runtime 合同。

优先提供显式停止会话运行、取消待回答问题的命令。保留 Ctrl+C 和等待超时只结束本地观察的现行语义。审批仍由使用者明确允许或拒绝；取消不表示已发生的外部写入被撤销。

验收：使用同一主体和原 sessionId 操作，核对原生运行及待回答事项的实际结果；覆盖不存在事项、已结束运行、其他用户、不同租户及响应丢失。停止后原历史仍可读取。

依据：[Runtime 会话入口](../../../xrain-harness/packages/xrain-agent-runtime/src/workbench.ts)、[CLI 对话命令](agent-chat.mjs)。

## Workforce 业务接入

Task、员工协作、频道消息和计划任务尚无 CLI 业务命令。Workforce 先确定面向 CLI 的宿主入口、登录会话、应用上下文和逐次授权合同；skills-hub 再按已确认业务范围接入。不能将平台令牌直接用于所有网页宿主路由，也不能通过通用记录更新绕过 Task 状态或消息规则。

计划任务由 Workforce 保存、调度并调用已有 Runtime。旧平台安排只保留读取历史和暂停；不恢复旧平台的编辑、启用或 Routine 到 Runtime 的执行链。周期安排与员工一次性检查分别核对身份、时间、重复领取、重启恢复和原 Session 的人工请求。

验收：获准本人完成选定业务动作，再从现有页面或业务接口回读；覆盖改派、撤权、退出、过期会话和结果未知。单个 Runtime 文本会话成功不代替业务结果。

依据：[Workforce 计划任务](../../../xrain-workforce/文档/项目/项目_XRAIN_WORKFORCE/技术设计/DOC-0018-Workforce计划任务存储与执行.md)、[宿主身份解析](../../../xrain-workforce/src/backend/bootstrap/http-server.mjs)。

## 不重复建设的能力与边界

- 查询总数、结构化条件、排序及聚合已有 `data query --query-json` 通路。受保护对象仍遵守平台限制。独立 count、distinct 等端点尚未映射，不等于统计能力整体缺失。
- 完整文件导入沿现有作业协议。原子导入预览、执行和原批次结果未接入，属于需要另行选择的命令范围；不因分块资格不足自动回退或循环旧原子导入。
- Runtime 地址按当前设计由服务方提供并保存到 profile。跨实例自动发现没有平台合同，不根据域名、端口或内部目录地址猜测入口。
- Host 原生登录已接入。Host OAuth 如有明确需求，先确认平台身份合同。
- Checkpoint、跨 Worker 接管和全树持久恢复受 Runtime 自身交付边界约束；CLI 不能单方面实现或宣称这些能力。
- 平台鉴权、授权、事务、业务效果和运行状态由原服务持有。CLI 不新增数据库、凭据目录、身份映射或第二套运行状态。

## 验证与交付要求

每项功能验证绑定实际 CLI 文件及服务版本。定向替身验证保留正常、拒绝、冲突、超时及回执丢失条件；涉及真实业务效果时，再按获准环境和受管身份核对结果。

当前仍需按实际使用范围补齐各部署的真实消费证据，以及 Linux/macOS 的安装、登录保护和文件操作证据。已有 Windows 定向测试及历史局部联调只证明其原版本和场景，不扩展为全部环境通过。独立系统测试、共享环境变更或部署另按用户明确目标执行。

源码修改由 skills-hub 构建并校验完整 Skill，更新 Workforce 当前副本；其他项目保持指向该入口。交付前核对命令实际指向、profile 字段、原会话和相关业务结果，保留其他任务的未提交修改。
