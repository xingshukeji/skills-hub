## 实施与验收

1. 核对真实包、函数、Jint 和构建响应合同，在 skills-hub 实现统一描述解析、模块编译、冻结源码、候选身份及输出。
2. 验证合成项目的资源和单独函数归属、当前源码变化、重复与并行构建、失败不报告旧包及单文件兼容；以真实平台构建器和 Jint 验证代表性输入。
3. 更新责任设计、CLI 使用指导和必要完整技能副本，核对独立分发仍只需要 Node；模块编译使用项目锁定依赖。
4. 待铵帮当前报价功能和相关共享改动稳定后迁移真实消费者，核对新旧资源语义、历史编排原文、公共顾客引用、函数、宿主、智能体和客户端消费。实际导入、安装和 Runtime 生效按已存在的同范围授权核对，未执行项如实保留。
