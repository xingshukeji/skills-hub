## 约束与验证

新增命令先核对服务路由、DTO、权限和直接消费者，不提供任意 URL 或数据库写入入口。CLI 不持有第二套身份、业务状态或 Runtime 状态。集合事务使用专用集合接口，不循环单条接口冒充原子写入。

所有写入按原动作明确发起；连接中断、超时或回执损坏时保留恢复标识，不自动重放。审批、影响确认与对外发送由调用者明确提供。实现命令不代表已授权操作真实账号、外部收件人或共享数据。

每组完成后运行相关定向测试，覆盖正常、拒绝、冲突和结果未知；修复原故障条件并保留合法相邻场景。源码构建后校验完整 Skill，最终运行 `npm run check`，同步 Workforce 完整副本并运行相关文档检查。真实依赖验证只使用获准的受管身份；未执行的操作系统或部署场景明确保留。

发现公共接口缺少必要合同、权限来源不明或实际服务不支持时，记录具体缺项，继续其他独立范围；不绕过原服务，也不为未知结果添加猜测行为。全部授权结果完成后更新设计与剩余文档，移除此计划及唯一任务登记，再精确提交推送。
