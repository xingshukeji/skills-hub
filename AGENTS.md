# Repository instructions

- Work in the saved Local checkout. Do not create or use worktrees unless the user explicitly requests one for this task.
- This repository hosts independent skills in `skills/<name>/`. Install and update from the default branch; do not add skill versions, release tags, or a version catalog.
- Every skill must work when only its own directory is copied. Never reference another local repository or require its build outputs.
- Maintain the XRain CLI in `src/xrain-cli/`. Run `npm run build` after changes and commit the generated `skills/xrain-cli/scripts/xrain-cli.mjs` and third party notices. Do not hand-edit generated files.
- Consumers need Node.js 22.12+ (24 LTS recommended); npm dependencies and bundling are only for maintainers. Do not require a .NET SDK or runtime installation.
- Keep credentials out of output, fixtures, and Git. Use temporary state directories and mock services for routine tests. For user-authorized live development verification, use dedicated synthetic users, roles, entities and packages; follow the target service's authentication and permission contracts. Keep live state and evidence in ignored `.local-validation/`.
- Preserve browser authentication, token-bound tenants, session protection, and package integrity checks when changing CLI behavior.
- Run `npm run check` before delivery. The README skill index is generated by `npm run index`.
