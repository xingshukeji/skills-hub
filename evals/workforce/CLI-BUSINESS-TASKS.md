# CLI 自然业务任务验证

本组用于检查用户未说出 CLI 时的能力发现、实际操作和权限边界。任务见 [cli-business-cases.json](cli-business-cases.json)，判定依据单独放在 [cli-business-rubric.json](cli-business-rubric.json)。它补充旧版平台管理场景，不重算历史报告的分数。

验证前保存实际修改前与修改后的完整技能、目录描述和加载路径。每个条件使用相同业务请求、主体、应用和工具；结果互相隔离。向执行者只提供自然请求、当时事实和实际可发现的技能目录，不提供 rubric 或命令答案。

真实产品验证复用已获授权的员工、固定身份和原生会话入口。读取已有资源不授予员工新工具或额外业务权限。消息、任务、计划和邮箱内容保存于受管的本机证据目录；报告使用脱敏的请求、命令、原回执与资源关联，不能提交凭据、客户正文或模型状态。

只读案例可在获准的真实环境执行。拒绝、缺工具及部分成功案例使用已存在的明确状态或隔离夹具，不为验证撤权、制造故障或创建真实业务资源。对写入、外部发送或权限改变的验证，先核对该业务动作的已有授权。

分别检查实际技能选择和读取、命令执行、原服务结果及最终业务结论。只回答计划、作者按已知答案操作、脚本替身通过或只看最终模型文本，都不能单独证明实际使用通过。

将用于改写、选择候选及最终检验的材料分开。需要独立执行者时沿用当前任务的委派授权；没有授权时继续作者走查、命令及加载验证，明确未取得独立行为证据，不通过其他模型入口绕过。实际产品中已获授权的模型会话验证按其业务范围记录，不当作盲测或总体正确率。
