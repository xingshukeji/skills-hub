# 验证技能的实际执行

这组隔离任务用于补充 `task-scenarios` 的选择和下一步检查。它要求实际审查或修改文件，不能用计划回答代替。夹具为合成业务，取材于已经出现的纠偏类型，不含客户资料或真实会话。

1. 在临时目录保存本次修改前、修改后的完整技能与所需路由。修改前是实际内容基线，不能无条件用较旧的 Git HEAD 替代。
2. 分别为两个条件复制 `fixtures/`；每个任务使用独立工作目录。向执行者提供 `cases.json` 中对应请求、上下文和该条件的技能目录，隐藏 `rubric.json`、另一条件及作者分析。
3. 执行者只操作该任务目录，运行其中已有工具，保存实际输出和最终回答。禁止访问真实平台、账号、发布入口或执行 Git 写入；不自行委派。
4. 按 `rubric.json` 人工核对实际增量、执行过程和结果。输入、只读目录及技能快照核对内容哈希；完整目录同步核对相对文件集及每个文件内容。
5. 分别报告结构检查、作者走查和独立执行。未经委派授权不能自行启动评估代理；准备好任务或作者跑过夹具不表示独立行为已通过。

需要比较后续真实效果时，记录原要求遗漏、重复确认和无效停顿；用户新需求、必要业务选择与权限请求不计为技能造成的返工。这组小样本不支持激活率、稳定性或对话轮数的总体结论。
