# 提交与恢复合同

客户端为一次提交保留 requestId，直到确认完成或确认撤回。网络超时只代表没有收到响应。请求可能仍在传输队列中；查询只返回已登记结果，所以 not-found 不证明该请求永远不会到达。

服务提供 withdraw(requestId)：若已完成则返回原结果；否则记录该请求的撤回标记，并拒绝同一 requestId 的后续受理。客户端完成“取消”动作后，要么展示已经完成的原结果，要么确认原请求不会再生效。允许撤回未知 requestId；不依赖先查询到请求。

服务的请求登记与状态查询使用同一个当前身份；本隔离范围不包含身份切换、真实网络或存储故障。应用正文与请求标识均为合成数据。
