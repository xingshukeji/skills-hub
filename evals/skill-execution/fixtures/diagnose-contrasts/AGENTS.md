# 隔离技能诊断任务

各 q 目录为互相独立的合成项目；不是历史真实会话。source-skills 是各项目的唯一编写源，installed-skills 是消费副本，项目入口由对应 AGENTS.md 指定。traces.jsonl 保存该项目任务发生时的消息和工具调用，不能用相邻项目替代本项目证据。

在各项目内完成已授权的诊断、必要技能/路由修正及原有本地业务工作。可以改项目内的来源、完整消费副本、app.mjs 和必要定向测试；保留原始请求、Runbook 和 traces.jsonl。只读请求仍只读。不访问真实网络、账号或远端，不执行 Git 写入，不启动代理。查询工具只读取本地响应文件。工作记录和结果留在本项目，不新增技能或长期台账。
